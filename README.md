This is a simulation of the core hypotheses of the Symphony of the Mind theory by Jits Krol built in Python for Linux, Windows and MacOS. All parameters have been fine-tuned to obtain the expected result,
and important mechanisms are still missing so this is just a proof of concept. An AI agent (Claude Opus 5.5) was used to help code this visualization and make the UI attractive. 
All mechanisms used are based on earlier, established research and predate this simulation.  

Open HOW TO RUN.txt for installation instructions. 

Using the simulation:
The simulation starts in training mode, with Hebbian learning and Feed Outside Experiences turned on. You can speed up training until a neural network emerges from co-activation. 
Then turn off Feed Outside Experiences, and activate one or more concepts to see how activity self-harmonizes into learned mutually reinforcing patterns of information. 

What can be simulated: 
1) Associative thought
2) Attention (the competition between possible next harmonies)
3) Motivation (setting the resistance higher and lower)
4) Emotional states through neuromodulation/peptides
5) Episodic/sequential memory through STDP

Limitations: 
1) This is a relatively small dataset, so associative thoughts have to make very large jumps. This can cause the model to get stuck in certain harmonies, and have trains of thought peter out without a good next harmony to jump to.  
2) The model does not include automated motivation (only manual tweaking of sliders). This means it doesn't get "bored" of recent thoughts, and can get stuck in dominant loops.
3) The model does not include short-term memory (this would only reinforce limitation 2), so it can't show the expected effects of a working memory.
4) The model does not include choices, feedback, result prediction, or actual behaviour being executed. Only associative thought.
